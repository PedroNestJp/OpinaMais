
  # Opina+

  This is a code bundle for Opina+. The original project is available at https://www.figma.com/design/sQpKAuRHLJqrBIXVzTBSkz/Opina-.

  ## Running the code

  Run `npm i` to install the dependencies.

  Copy `.env.example` to `.env` and point `VITE_API_BASE_URL` to your backend (ex.: `http://localhost:8080/api/v1` for the Laravel docker-compose).

  Run `npm run dev` to start the development server.
